# 通鉴地图 · Tongjian Atlas

读《资治通鉴》时，把地名、人物和政权放回同一张地图。

通鉴地图是一款面向 **东晋十六国—南北朝 · 至隋统一（公元 304—589 年）** 的历史地理阅读与推演工具。你可以沿时间轴查看政权变化，寻找古地名，摆放人物棋子、组织编队，并用自己的标注和疆域编辑记录阅读理解。

时间轴延伸至589年，不代表逐年精确疆界或全时段核验：304—439年保留原始核验范围，440—589年为有来源的断面概略重建与局部区域复核。原有CHGIS地名底本仍来自304—439年九个采样断面；新增时段并非完整城市普查。

**[打开在线地图](https://kelvinduanmu.github.io/tongjian-atlas/)** · **[查看慕容家族谱系](https://kelvinduanmu.github.io/tongjian-atlas/genealogy.html?family=murong)** · **[反馈问题](https://github.com/kelvinduanmu/tongjian-atlas/issues)**

> 在线版无需注册。你的编辑只保存在当前浏览器，不会公开给其他访问者，也不会修改项目原始资料。请定期使用页面上的“导出个人副本 JSON”备份。

## 快速上手

1. **选择年份**：拖动底部时间轴，或使用播放、前后箭头查看历史断面。
2. **寻找地点**：在左侧“寻找地名与水名”中输入名称，例如“襄国”“枋头”“芍陂”。点击结果定位，查看出处、年代和定位说明。
3. **放置人物**：打开“人物战棋”，先搜索已建人物避免重复，再新增人物、填写简介和所属势力，在地图上选点保存。
4. **记录自己的理解**：使用“添加地点”保存备注，或在“编辑疆域”中画出自定义范围。所有用户编辑都会与原始资料区分。
5. **保存备份**：离开前导出个人副本。换电脑、换浏览器或改用本地版本时，可通过导入备份继续使用。

鼠标拖动空白处平移地图，滚轮缩放；手机可触控浏览。人物棋子和队伍军旗也可以拖动，但正在绘制范围、选择编队成员或保存时，会暂时锁定相关操作。

## 能做什么

### 地图、时间轴与古地名

- 在固定地理底图上查看不同年代的政权分布，不因切换年份而改变地图视野。
- 搜索城邑、州郡县治所、河流与湖泊，查看名称、资料年代、坐标精度和来源链接。
- 按地点类型、年份筛选标注，开关政权填色、城邑及水域名称等图层。
- **地形起伏默认开启**，帮助辨认山地、盆地与行军通道；可在左侧关闭。影像随站点提供，不需要额外地图密钥；仅作现代地形参照，不是古地貌复原。
- 同坐标存在多条地名时，可在弹窗中点击“选为标名”，切换该位置在地图上的名称。选择保留在当前页面会话中；刷新后恢复默认。
- 通过“编辑显示年代”手动调整某条地点记录的可见年份，也可恢复原始显示规则。**这只改变显示，不改写原资料的建置年代。**

**找不到地名时怎么办？** 搜索会列出匹配的原始地点，即使它不在当前年份的有效期内。先核对同名异地、记录编号与年代；也可以取消“仅显示所选年份有效建置”，或设置自己的显示年代。历史地点库并非穷尽所有地名，欢迎附出处反馈缺项。

### 人物战棋

- 自定义人物姓名、简介、角色和所属势力，在地图上摆放并拖动。
- 君主与大臣使用不同棋子形状，所属势力以颜色区分；拖过国界不会自动改变阵营。
- 搜索已建人物，新建时也会提示同名记录，帮助减少重复创建。
- 点击棋子查看资料、修改或删除；也可以“隐藏人物”，保留资料与位置，在左侧搜索后恢复。
- 人物位置跨年份固定，方便跟随阅读手工推演，**不是自动复原的历史行踪**。

### 人物编队

- 从人物列表勾选成员，或点击棋子后使用“从地图组建编队”。
- 为编队命名并指定主将；每队 2—50 人，每人只能加入一个编队。
- 保存后整队显示为一面军旗，地图上只标主将姓名。拖动军旗会移动全体成员并保持相对布局。
- 点击军旗查看队伍构成；编辑时可调整成员、更换主将，解散后恢复独立棋子。
- 隐藏主将会暂时隐藏整队军旗，但不解散编队；恢复主将后重新显示。

### 地点标注与疆域编辑

- “添加地点”提供候选位置、来源与精度说明，核对后可保存为自己的标注并填写备注。
- 选择地点、开始生效年与目标势力，逐点绘制自定义疆域范围，确认后保存。
- 编辑从生效年延续到后续年份；之后的重叠编辑可能改变局部结果。
- 点击编辑记录可用虚线查看该次保存的原始范围，再次点击取消预览。可以撤销单条记录，或清除编辑恢复原始图。

> 手绘范围不是已考证县界。虚线显示的是该条记录的保存范围；若有后续重叠编辑，撤销后的实际变化不一定覆盖整块虚线范围。

### 家族谱系

- 独立谱系页面展示重要人物的亲子关系，首批包含慕容家族核心人物。
- 支持姓名搜索、点击人物查看直接亲属和关系出处，以及缩放、定位和手机阅读。
- 人物战棋可链接到匹配的谱系节点。同名不等于同一人，请结合身份核对。
- 亲子连线不代表皇位继承；未收录的亲属不表示不存在。
- **自动检索并生成新谱系仅在配置了资料索引的 Python 共享版中提供**；在线个人版可阅读人工选录及已导入的谱系。

## 数据保存与备份

### 在线个人版

在线地图是你的**本机浏览器个人副本**，其他访问者不会看到你的修改。

- 刷新页面后，已保存内容仍会保留。
- “导出个人副本 JSON”包含人物、编队、隐藏状态、地点标注、疆域编辑、显示年代和已保存谱系。
- **导入是替换，不是合并**。导入前请先导出当前副本，避免覆盖需要保留的修改。
- 不同网址、端口、浏览器和设备各自拥有不同副本，不会自动同步。
- 清理网站数据、使用隐私窗口或浏览器回收存储，可能导致数据丢失；不要把浏览器当作唯一备份。

在线个人版的地点检索使用随站点提供的本地资料，人物简介可手工填写。它不提供在线人物简介检索、自动家族谱系生成，也不会把个人编辑上传到 GitHub。

### 本地共享版

同一 Python 服务的访问者共同读取和修改服务器上的保存数据，适合个人跨浏览器使用，或在可信局域网共同阅读。它与在线个人版**不会自动同步**，个人版的导入按钮也不是服务器保存目录的迁移工具。

## 本地部署

需要 **Python 3.10 或更新版本**。日常运行不需要 Node.js、npm 或额外数据库。Windows 如果没有 `python3` 命令，可使用 `python` 或 `py -3`。

先获取源码并进入项目目录：

```sh
git clone https://github.com/kelvinduanmu/tongjian-atlas.git
cd tongjian-atlas
```

也可以在 GitHub 点击 **Code → Download ZIP**，解压后在项目目录打开终端。

### 方式一：本地个人版

适合自己使用，编辑仍保存在浏览器中，与在线版相同：

```sh
python3 scripts/build_pages.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

打开 **http://127.0.0.1:8000/**。

首次运行或更新源码后重新执行构建命令即可。不要直接双击 `index.html` 代替 HTTP 服务。下载并构建后，本地地图和个人编辑不依赖公网；打开外部史料链接仍需联网。在线站点没有离线缓存保证，不能依赖断网后重新加载网页。

### 方式二：本地／局域网共享版

在源码目录运行：

```sh
python3 atlas_server.py --bind 127.0.0.1 --port 8765 --data-dir ../tongjian-atlas-data
```

打开 **http://127.0.0.1:8765/**。数据保存在项目目录之外的 `tongjian-atlas-data` 文件夹，而不是浏览器中。备份或迁移时，先停止服务，再复制整个保存目录。

如果希望同一局域网的其他设备访问，把监听地址换成本机的实际局域网 IP，例如：

```sh
python3 atlas_server.py --bind 192.168.1.100 --port 8765 --data-dir ../tongjian-atlas-data
```

其他设备访问 `http://192.168.1.100:8765/`，并确保系统防火墙允许可信局域网访问该端口。

**共享版没有登录和权限隔离，所有能够访问的人都可以修改数据。仅用于可信局域网，不要直接开放到公网。** 共享服务启动时会提供对应运行模式，不需要手工修改网页配置。

### 共享版的可选在线功能

- **人物简介检索**：需要能够访问外部资料服务。网络失败、限流或查不到资料时，可以直接创建自定义人物并手写简介。
- **自动家族谱系**：先了解并接受来源站点的使用条件，再生成本地姓名索引：

  ```sh
  python3 scripts/fetch_genealogy_index.py --acknowledge-source-terms
  ```

  索引生成在源码目录，完成后重启共享服务。随后可从人物弹窗点击“新增家族谱系”，核对候选身份，再生成并保存。索引覆盖有限，亲属资料来自外部二手来源，不保证完整或准确；每条关系应结合出处核对。

这些在线功能不可用时，不影响手写人物、编队、地图编辑及已有谱系阅读。项目不附带受限传记摘录或在线人物索引；自行取得的资料及个人备份也不应随意公开上传。

## 如何理解地图上的历史信息

本项目服务于读史定位和个人推演，不是精确历史 GIS 或最终考证结论：

- 疆域采用有出处的区域概略重建，不是精确州郡县界；两个历史断面之间不插值生成逐年疆界。
- 行政隶属、实际控制和人物驻地不是同一回事；用户编辑不改变原始史料。
- 古地名可能同名异地、迁治或存在定位争议，请查看每条记录的出处和精度说明。
- 现代地形、水系及代表点不能直接当作古代河岸、城墙或战场的精确位置。
- 原图扫描、部分参照图层和完整原始核验报告未随公开版提供。详情见[资料来源与发布范围](https://kelvinduanmu.github.io/tongjian-atlas/sources.html)。
